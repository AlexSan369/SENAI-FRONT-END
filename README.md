# SENAI-FRONT-ENDAula 02 - Introdução ao JavaScript e Manipulação do DOM

Este repositório contém o código-fonte de referência e as orientações para a Aula 02 do curso técnico de Desenvolvimento Web (2º Ano).

Visão Geral da Aula

Carga Horária Total: 4 horas-aula (4h)

Público-Alvo: Alunos do 2º Ano do Ensino Técnico em Informática / Desenvolvimento de Sistemas.

Prerequisitos da Turma: Conhecimento introdutório de HTML5 e CSS3 (abordado na Aula 01).

Objetivo Principal: Apresentar o JavaScript como a camada de comportamento da Web, ensinando a manipular elementos HTML via DOM e reagir a eventos de clique.
